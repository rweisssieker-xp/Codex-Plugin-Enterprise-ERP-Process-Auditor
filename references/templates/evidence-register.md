Use one evidence ID per source-backed statement or discrete source item. Set **Statement Type** to exactly one of: `fact`, `stakeholder observation`, `calculation assumption`, or `hypothesis`. Keep quotations and fields to the minimum needed for the stated use; do not reproduce confidential data unnecessarily.

Do not infer inaccessible content or fill missing source fields. Record a limitation in **Use Limit** and create an Evidence Gap Register item when the missing content affects a decision.

For an unsupported file format, state the supplied format and the requested conversion format in **Needed Evidence**. A gap is not proof that a condition exists; it only limits what can be concluded.

## Hypothesis / Gap Register

Use this register only for an evidence-free hypothesis. It must reference one or more Gap IDs that specify the evidence needed to validate or reject the hypothesis. A Hypothesis ID is explicitly not an Evidence ID: do not place an unsupported hypothesis in the Evidence Register or use it as support for a fact, calculation, recommendation, or decision.
