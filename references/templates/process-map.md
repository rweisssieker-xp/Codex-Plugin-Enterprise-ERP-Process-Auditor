## Use rules

- Identify process scope, entity, period, and outcome before mapping.
- Mark implementation behavior as `standard`, `custom`, or `unknown`; do not infer ERP product capability or configuration without user-supplied release and configuration evidence.
- Record a system handoff whenever responsibility or data moves between a system, spreadsheet, email, file, or team.
- Link a potential weakness to a Finding ID only after the relevant evidence has been reviewed. A Gap ID or Hypothesis ID is not evidence.
- Treat control descriptions as process observations, not legal, tax, compliance, audit, or assurance conclusions. Refer material control questions to the accountable internal owner.
